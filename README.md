# Веб-сервис «СтройДом»

**Автоматизация взаимодействия строительной компании с клиентами**

## Технологии
- PHP
- MySQL
- HTML5 / CSS3 / JavaScript

## Функционал
- Личный кабинет клиента
- Панель администратора
- Каталог услуг
- Портфолио
- Блог
- Версия для слабовидящих (ГОСТ Р 52872-2019)
