# Веб-сервис «СтройДом»

Веб-сервис для автоматизации взаимодействия строительной компании с клиентами.

## Технологии

- PHP
- MySQL
- HTML5 / CSS3 / JavaScript

## Возможности

- Публичный сайт: услуги, портфолио, блог, контакты
- Онлайн-калькулятор стоимости строительства
- Регистрация и вход для клиентов
- Личный кабинет клиента с отслеживанием заявок
- Панель администратора: заявки, клиенты, услуги, портфолио, статьи
- Разграничение прав доступа для трёх ролей: администратор, менеджер, клиент
